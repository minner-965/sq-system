# Phase 13 contact readiness rules

Status: MC04 approved independent contact/readiness projection; existing production send gates remain authoritative.

Report independent, potentially multiple readiness labels: NAMED_BUYER_READY, EMAIL_READY, PHONE_READY, WHATSAPP_READY, FORM_READY, CONTACT_RESEARCHING, NO_CONTACT_FOUND. Use only existing traceable route/verification facts. Discovery of an address does not prove mailbox deliverability. A named buyer is optional when an eligible official company/department mailbox exists.

Keep contact availability distinct from send permission. Retain address/company suppression, bounce, opt-out, verification freshness, prior sends, draft version and approval facts. Missing inputs remain unknown/not evaluated, never fabricated eligible. Report current manual-gate evidence and any outstanding checks; a dry-run band is not an approval. Future AUTO_FIRST_TOUCH policy is outside MC03 and is not activated here.

No contact lookup, mailbox verification, test email, real email, approval mutation or background workflow activation is part of MC04. Existing verification timestamps and evidence are read as stored. Absence of a route never changes business fit; it can produce a contact-researching state separately. Active business membership is not mail authorization. Previously contacted companies remain business opportunities; first-contact queues may independently exclude them. Unknown authorization is displayed as not evaluated, never eligible.
