# 演示启动说明

给别人看系统之前，按这个顺序来。平时自己用不需要第 2 步。

## 1. 开机后

正常情况什么都不用做：

- 登录 Windows 后，发布程序会自己最小化启动，并顺手把 Docker Desktop 打开。
- Docker 起来后，系统（数据库、网页、后台任务）自动恢复运行。
- 等一两分钟，在本机浏览器打开 http://localhost:3000 能看到登录页，就说明好了。

如果登录页打不开：打开 Docker Desktop，等左下角变绿，再双击 `publisher\start-publisher.cmd`。

## 2. 生成演示链接

双击 `scripts\hz\start-demo.cmd`。

- 窗口里会出现一行 `https://xxxx.trycloudflare.com`，这就是演示链接，发给对方。
- 链接每次都不一样，只在这个窗口开着的时候有效。**关掉窗口，链接立刻失效。**
- 对方打开后要先登录，没有账号看不到任何内容。
- 这台电脑要保持开机、联网、不睡眠。

## 3. 演示账号

| 账号 | 身份 | 能做什么 |
|---|---|---|
| admin | Simon，管理员 | 全部，包括底价、账号、设置 |
| boss | 老板 | 只能看，不能改；看不到底价 |
| chen | 陈经理，招商 | 商铺写字楼板块 |
| lin | 林经理，招商 | 酒店公寓和餐饮板块 |

密码在这台电脑的 `data\accounts.local.txt`，每个账号以最后一行为准。这个文件不上传。
给外人演示建议用 boss 账号。演示完想换密码：在 `services\demo-dashboard` 下运行 `npm run user:set -- --username boss`。

## 4. 演示结束

关掉“恒兆演示链接”那个窗口。其他的不用动。

## 常见情况

| 现象 | 处理 |
|---|---|
| 对方打开链接很慢或打不开 | 链接走的是境外线路，国内手机网络偶尔会慢。让对方换个网络再试，或者重新生成一个链接 |
| 密码连续输错被锁 | 等 15 分钟，或者用上面的命令重置密码 |
| 内容发布页显示“发布程序没有在运行” | 双击 `publisher\start-publisher.cmd` |
| 抖音账号显示“需重新扫码” | 管理员在“发布账号”页点“扫码登录”，在弹出的窗口里用抖音扫码 |
