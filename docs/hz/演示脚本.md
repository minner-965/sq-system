# 演示脚本

大约 10 分钟。先用 boss（只读）给对方看，需要动手操作的环节换成 admin 在自己电脑上做。
开始前按《演示启动说明》把链接生成好，自己先登录一遍。

## 1. 总览（1 分钟）

打开首页。

- 四个数字：在租房源 54 套（商铺 10、写字楼 44，共 6,759 ㎡）、本周新发现企业、本月看场、今日待跟进。
- 招商漏斗：从待联系到已签约，每一步有多少家。
- 右上角可以切“商铺写字楼 / 酒店公寓 / 餐饮”，整页跟着换。
- 下面是内容发布的进度和待跟进客户。

要说的话：数字都来自推租表和实际跟进记录，没有填充数据。现在漏斗很空，是因为系统刚开始用。

## 2. 企业发现（2 分钟）

点“企业发现”。

- 列表是恒兆广场周边的企业，按匹配程度排序，每家有分数和理由。
- 点开一家看评分依据：距离、行业、规模、最近有没有扩张或搬迁的迹象。
- 已经在恒兆广场里的商户不会出现。
- 觉得合适的点“通过”，就进了招商客户；不合适的点“不合适”并选原因。

要说的话：每天早上 7 点半自动找一批，招商人员只需要过一遍。

## 3. 企业详情与房源匹配（2 分钟）

点“招商客户”，打开“中国水电十五局广州黄埔项目群”。

- 上面是企业基本信息和距离。
- 中间填需求：业态、面积范围、预算、要不要明火。
- 点“按需求推荐房源”，系统从 54 套在租房源里挑出合适的，写明为什么合适。
- 用 admin 登录时，意向价低于底价会有提示；其他账号看不到底价。

## 4. 跟进（1 分钟）

还在这家企业的页面。

- 改阶段：待联系 → 已联系 → 已看场 → 洽谈中 → 已签约。
- 写一条跟进记录，设下次跟进时间。
- 回到首页，“待跟进”里会按时间排出来；到点会有提醒。

## 5. 内容发布（抖音）（3 分钟）

点“内容发布”，打开“1 栋 13 层 193 平精装写字楼招租”。

- 素材是房源照片和几句要点，关联了推租表里的 1307 室。
- 系统按四个平台各写了一版文案，风格不一样。可以改，可以重新生成。
- 每一版都要人点“确认”才会发，可以选时间。排期日历里能看到哪天发什么。
- 抖音这一条已经真实发出去了，点链接可以看到帖子。

再点“互动收件箱”，切到“已转线索”。

- 有人在这条帖子下评论“可以想要”，系统判断是询价并提醒。
- 回复是系统起草、人确认后发到抖音上的。
- 一键转成线索，在“招商客户”里就是“抖音用户 mediou”，挂在 1307 室，评论原话和回复都在跟进记录里。

要说的话：发什么、回什么都要人确认，系统不会自己对外发东西。小红书、视频号、朋友圈是下一期。

## 可能被问到

| 问题 | 回答 |
|---|---|
| 企业信息哪来的 | 地图上的公开企业信息和公开网页，不含个人隐私 |
| 会不会自动给人打电话发消息 | 不会，所有对外的动作都是人点了才发 |
| 底价谁能看 | 只有管理员 |
| 换台电脑能用吗 | 现在跑在这台电脑上，正式用会搬到云服务器 |
