# 内容发布与获客 操作手册

适用对象：上传素材的同事、招商运营人员、管理员
最后按实际界面核对：2026-10-12

侧边栏里和本手册有关的页面：内容发布、互动收件箱、发布账号、留资线索、需求发现、企业发现、招商客户、报表、系统设置。

---

## 一、每天要做的事（招商运营人员）

1. 打开系统，看侧边栏“互动收件箱”旁边的数字，有数字先处理（第四节）
2. 看右上角小铃铛里的提醒。常见的有：发布失败、抖音要求短信验证、账号要重新扫码、发出去的内容缺了正文、发出去的内容在平台上找不到了、发现了新的需求帖
3. 看“内容发布”里还没确认的草稿，核对后确认并排时间（第三节）
4. 看“需求发现”的待处理（第六节）
5. 看“发布账号”，有账号显示要扫码就扫（第七节）
6. 每天在手机上看一次：小红书和视频号的评论、私信，抖音的私信（系统读得到但回不了）

电脑上开着系统页面时，新的意向消息会在桌面弹提醒。第一次浏览器询问时点“允许”。

## 二、上传素材

1. “内容发布”→“上传素材”
2. 主题：一句话说清要宣传什么，例如“1 栋 13 层 193 平精装写字楼招租”
3. 内容类型：房源 / 活动 / 酒店 / 餐饮。房源可以选“关联房源”，楼层面积会带出来
4. 传图片（最多 18 张，JPG、PNG、WebP）或一个视频（MP4、MOV，竖屏更好）
5. 补充说明：写清楚画面里有什么、卖点是什么。**文案只会用主题、补充说明和系统里的资料，没写的不会出现**
6. 目标平台：视频号只能发视频，没有视频时不要勾

拍摄建议：光线充足、横平竖直；房源拍门头、内部全景、窗外；不要拍到租户和客人的脸。

## 三、生成文案、确认、发布

1. 打开素材，点“生成全部文案”，每个平台各写一版
2. 逐条核对：
   - 事实对不对：面积、楼层、位置、时间、设施。写了没有依据的话要删掉
   - 不能出现底价，不能承诺没批准的优惠
   - 口吻是不是我们自己人在说话，不能假装成客人
3. 直接改文字后点“保存修改”；不满意点“重新生成”，旧版本保留在“历史版本”里
4. 每个平台单独确认：选“定时”和时间，或“立即发布”，点“确认”。**没确认的不会发**
5. 已确认还没发的，可以点“撤回”
6. 同一个账号两条之间至少隔 10 分钟，系统自动顺延；每个账号每天有上限

**抖音发视频会要短信验证**：到点后电脑上弹出浏览器窗口，系统已经替你点了“获取验证码”，把手机收到的验证码填进**那个窗口**点“验证”。10 分钟内不填，这条算失败。验证码不要发给任何人、不要填到别处。

**发完以后**：

- 状态变成“已发布”，带“查看帖子”的链接（视频号没有网页链接）
- 系统会把平台上实际存下的文字读回来和确认稿对一遍。如果提醒“发出去的内容缺了正文”，到平台上看一眼，需要就删掉重发
- 每 6 小时读一次浏览、点赞、评论等数字，显示在卡片上，30 天后不再读
- 失败不会自动重发。看失败原因和截图，处理后重新确认

**在平台上删了帖子**：在那条卡片上点“已在平台上删除”。如果没点，系统发现它不见了会提醒你。删掉以后想再发，点“重新发一条”，文案会带过来，核对后再确认。

**同一条素材再发到别的平台**：素材页“这条素材再发到：”后面点平台名。

**留资二维码**：卡片上点“留资二维码”，把二维码放进图片、视频或评论区。客人扫码填了称呼、电话和需求，会直接进“招商客户”的待联系，并出现在“留资线索”里。（目前二维码里是内部地址，外面的人扫不开；等有了固定的公网地址才能对外用。）

## 四、处理评论和私信

1. “互动收件箱”。系统每小时读一次，急的时候点“立即检查”
2. 四栏：未处理、处理中、已转线索、已忽略。超过 2 小时没处理的标红
3. 每条能看到对方原话、来自哪条帖子、系统判断的类型和依据。判断错了直接改
4. 回复：
   - **抖音评论**：点“生成回复”，改好，点发送，系统替你回到那条评论下
   - **私信（所有平台）和小红书、视频号的评论**：系统发不了。写好后点“复制”，到手机上回，回完点“已手动回复”
   - 目的都是请对方留电话或微信，不在评论区报价
5. 对方留了电话、微信、QQ、邮箱，系统会自动认出来并按意向处理
6. 有意向的点“转成线索”，来源、帖子、昵称、原话自动带进客户档案；同一个人再来会并到原档案
7. 广告和无关的点“忽略”
8. 在手机上看到、系统读不到的消息，点“手工录入”补进来

读得到什么：

| 平台 | 评论 | 私信 |
|---|---|---|
| 抖音 | 读得到，能回 | 只读“陌生人私信”，回要在手机上 |
| 小红书 | 只有数量，内容在手机上看 | 读不到，在手机上看 |
| 视频号 | 只有数量，内容在手机上看 | 读不到，在手机上看 |
| 朋友圈 | 等专用手机 | 等专用手机 |

## 五、企业发现和中标工程

1. “企业发现”：系统每天在恒兆广场周边找企业并打分，列出“需求依据”（强、中、弱）。打电话前可以点“现在查一下”把这一家再查一遍
2. “黄埔新中标的工程”：刚在黄埔中标的施工单位要进场，需要住宿、用餐、临时办公。合适的点“转入跟进”，不合适的点“不合适”
3. 转入后在“招商客户”里。打电话：企业档案里点“打电话并记录”，照着提示的问题问，打完记下结果。**系统不会自己打电话**

## 六、需求发现

系统每天两次用搜索专用的小号，在小红书和抖音上搜公开帖子，找出正在找铺位、找写字楼、找酒店、找餐厅的人。

1. “需求发现”→“待处理”。每条有原话、发帖时间、是哪个词搜到的、属于哪个板块、帖子里写明的面积预算区域，以及判断依据
2. 先点“看原帖”，确认对方确实在找
3. 值得跟的点“转成线索”，进“招商客户”待联系，来源记为“主动发现”
4. 想联系对方：点“联系对方”→“起草一条”，**改成自己的话**，点“复制”，到手机上打开原帖，贴进评论发出，回来选用的是哪个账号、点“已联系”
   - 同一个人只联系一次；一个账号一天最多主动联系 10 人
   - 不报价、不留电话微信、不群发一样的话
5. “不合适”：只关掉这一条。“对方不感兴趣”：这个人以后的帖子都不再出现
6. “筛掉的”一栏是系统判断为中介、同行广告或无关的。判断错了可以在那里选板块转成线索
7. 管理员可以点“搜索关键词”改词（一行一个，写成“地方 + 想找什么”）。某个词老是搜出中介广告，就删掉或换掉

## 七、发布账号和扫码登录（管理员）

1. “发布账号”里每个账号一张卡片，显示登录状态、今天发了几条
2. 显示要扫码时，点“扫码登录”，电脑上会弹出浏览器窗口，用对应平台的手机 App 扫
3. 各平台登录能保持的时间不一样：视频号大约一天，抖音和小红书通常一到几周
4. 添加账号：点“添加账号”，选平台和用途。**搜索专用的小号用途选“只用来搜索”，不要拿发帖的号去搜**
5. 页面上方有两行状态：发布程序是不是在线、浏览器走的是不是本机宽带。显示不在线时，发布和读取都停了，见《运维与故障处理》

## 八、报表

“报表”里有：招商漏斗、各渠道效果（发了几条、多少互动、多少留资、转了多少线索）、每个人的工作量、需求依据准不准。右上角可以导出 Excel。

## 九、常见提醒和处理

| 提醒 | 意思 | 怎么做 |
|---|---|---|
| 需要扫码登录 | 平台登录过期 | 管理员扫码，然后在失败的那条上重新确认 |
| 抖音要求短信验证 | 发视频时平台要验证本人 | 在弹出的浏览器窗口里填验证码 |
| 发布失败 | 见卡片上的原因和截图 | 处理后重新确认。提示“页面变了”一类的交给开发 |
| 发出去的内容缺了正文 | 平台上只有标题 | 到平台上看，删掉后点“重新发一条” |
| 发出去的内容在平台上找不到了 | 被删或被下架 | 自己删的就点“已在平台上删除”；不是就到手机上看下架通知 |
| 搜索专用账号要重新登录 | 连着两次没搜成功 | 在“发布账号”里给那个小号重新扫码 |
| 还没有配置大模型 / 大模型服务不可用 | 模型接口没配或欠费 | 文案和回复先手写，通知管理员 |
| 朋友圈已暂停发布 | 手机上发失败过一次 | 看原因，处理后在“发布账号”里点“恢复发布” |

系统发布失败后不会自己重试，避免重复发帖。
