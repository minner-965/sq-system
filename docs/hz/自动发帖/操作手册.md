# 内容发布中心 操作手册

适用对象：全体员工（上传素材）、运营招商人员（确认发布、处理消息）、管理员（账号和设置）
对应需求：功能需求.md v1.0
说明：本手册按需求编写。系统上线时由开发方按实际界面核对一遍，并补上截图。

---

## 一、每天要做的事（运营招商人员）

1. 打开系统，看侧边栏“互动收件箱”的数字。有数字就先处理消息（第四节）
2. 看“内容发布中心”里待确认的草稿，确认并排好发布时间（第三节）
3. 看“发布账号”页面，如果有账号显示“需重新扫码”，按第五节处理
4. 下班前看一眼排期日历，确认第二天要发的内容都已确认

系统要开着页面才会弹出桌面通知。建议在工作电脑上一直开着系统页面，并在浏览器第一次询问时点“允许通知”。

## 二、上传素材（全体员工）

1. 进入“内容发布中心”，点“上传素材”
2. 填写主题，一句话说清楚这次要宣传什么，例如“1 栋 5 楼 200 平写字楼招租”
3. 选择内容类型：房源 / 活动与品牌 / 酒店 / 餐饮
4. 如果是房源，在“关联房源”中选择对应铺位，楼栋、楼层、面积会自动带出
5. 上传图片（最多 18 张，第一张作为封面）和视频（可选，竖屏更好）
6. 在“补充说明”里写清卖点，例如临街、可分割、交通方便
7. 目标平台默认全选。不适合某个平台时取消勾选，例如只有图片时可以取消抖音和视频号
8. 点“提交”。之后可以在“我的上传”里看到状态

拍摄建议：光线充足，横平竖直；房源要拍门头、内部全景和窗外视野；不要拍到租户和客户的脸。

## 三、生成、确认和排期（运营招商人员）

1. 在素材详情页点“生成文案”。系统会为每个平台各写一版
2. 逐个平台检查：
   - 事实是否正确：面积、楼层、位置、活动时间
   - 不能出现底价，也不能承诺未经批准的优惠
   - 语气是否合适
3. 需要修改时直接改文字；不满意可以点“重新生成”，旧版本会保留
4. 每个平台单独点“确认”，并选择发布时间；也可以选“立即发布”
5. 已确认、还没发出的任务可以在排期日历里“撤回”
6. 发布后，状态变为“已发布”并显示帖子链接；失败会显示原因，见第六节

注意：

- 同一账号两次发布至少间隔 10 分钟，系统会自动顺延
- 朋友圈每天最多发 3 条，超出部分会排到第二天

## 四、处理评论和私信（运营招商人员）

1. 进入“互动收件箱”。系统每小时检查一次各平台；急的时候点“立即检查”
2. 收件箱分为四栏：未处理、处理中、已转线索、已忽略。超过 2 小时未处理的消息会标红置顶
3. 打开一条消息，可以看到对方原话、来自哪个帖子，以及系统判断的类型和判断依据。类型判断错了直接改
4. 回复：
   - 点“生成回复”，系统会起草一条回复，目的是请对方留电话或加工作微信
   - 修改后点“确认发送”，系统会代为发出
   - 如果提示“无法自动发送”，就复制回复内容，到手机上手动回复，再点“已手动回复”
5. 转线索：对有意向的消息点“转成线索”。来源平台、帖子、昵称和原话会自动带入；同一个人之前来过，会合并到原线索
6. 广告和无关消息点“忽略”

小红书个人号的私信系统读不到。收件箱会提示“私信请在手机上查看”，请每天在手机小红书上看一次私信。有意向的话，手动点“新建线索”，来源选“小红书私信”。

## 四之二、需求发现（运营招商人员）

系统每天会在小红书、抖音上搜索两次，找出正在发帖找铺位、找写字楼、准备开店的人。

1. 进入“需求发现”，每条记录显示原帖、对方昵称，以及系统识别出的面积、预算、区域和行业
2. 先点开原帖，确认对方确实有需求
3. 有价值的点“转成线索”，来源会自动记为“主动发现”
4. 需要联系时点“生成联系话术”。修改后确认，系统会用发布账号评论或私信对方。每个账号每天最多主动联系 10 人
5. 没有价值的点“不感兴趣”，这个人以后不会再出现
6. 搜索关键词在“设置 → 搜索关键词”中维护。发现某个词总是搜出中介广告时，就删掉或换掉它

## 五、发布账号和扫码登录（管理员）

1. 进入“发布账号”，每个平台一行，显示登录状态和最近一次登录时间
2. 状态为“需重新扫码”时，点“扫码登录”，用该平台的手机 App 扫描页面上的二维码
3. 扫码成功后状态变为“正常”。各平台通常一到四周需要重新扫一次
4. 朋友圈用的是插在 minm 上的安卓手机，不需要扫码；状态显示“手机未连接”时，见运维文件第三节

## 六、常见提示和处理办法

| 提示 | 意思 | 怎么做 |
|------|------|--------|
| 需重新扫码 | 平台登录过期 | 管理员按第五节扫码，然后在失败任务上点“重新发布” |
| 发布失败：页面元素未找到 | 平台改版，脚本失效 | 暂停该平台的发布，交给开发人员处理（运维文件第四节） |
| 发布失败：内容违规 | 平台审核没有通过 | 修改文案或图片后重新确认 |
| 手机未连接 | 安卓手机断开或没电 | 检查数据线和电量，见运维文件第三节 |
| 模型服务不可用 | 模型接口欠费或故障 | 文案和回复可以先手写；通知管理员充值或切换服务商 |
| 今日朋友圈已达上限 | 当天已发 3 条 | 系统会自动排到第二天 |

系统发布失败后不会自动重试，避免重复发帖。处理完原因后，请人工点“重新发布”。
