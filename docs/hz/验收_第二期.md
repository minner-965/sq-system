## 汇总

- 完全通过：2、3、5、7、9、11
- 部分通过，剩下的卡在外部条件：
  - 专用安卓手机 → 1（朋友圈）、4（朋友圈）、8（真实发布）
  - 搜索专用小号 → 10（真实搜索）
  - 一条视频号测试评论 → 4（视频号评论）
  - 平台限制，做不到 → 4（小红书评论内容）、6（私信发送）

## 和原需求不一样的地方（都已和 Simon 说明）

- 私信不由系统发送：平台不送达。
- 主动联系由人在手机上发，系统只起草、记录、限次数。
- 抖音发视频每次都要短信验证，要有人在电脑前填验证码。
- 视频号登录大约一天过期，比预想的“一到四周”短得多。
