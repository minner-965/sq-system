# 小红书 · 文案风格

## 平台特点
- 用户是主动搜索的：“广州办公室出租”“黄埔 写字楼”“演唱会 住哪”。标题和正文里出现他们会搜的词，才会被找到。
- 大家信“真人的经验分享”，不信广告腔。要像一个在这里上班或做招商的人，把自己知道的讲给来问的人听。
- 长一点没关系，但每段只讲一件事，方便人跳着看。

## 标题（不超过 20 字）
- 结构：地点或人群 + 具体信息 + 一个看点。例如“黄埔 193 平办公室 15 人团队刚好”这种结构。
- 里面要有一个搜索词（写字楼、办公室、商铺、酒店、潮汕菜）。
- 可以用一个数字。不用“绝绝子”“天花板”“谁懂啊”这类词，不用感叹号。

## 正文（200–800 字，分 4–6 段）
按这个顺序写，每段两到四句，段与段之间空一行：
1. 开头：一句话说清这是什么、在哪，适合什么样的人或团队。
2. 空间或产品本身：面积、格局、配置、交付，逐项说，可以讲怎么用（隔间做会议室还是财务室）。
3. 费用：公开报价或“欢迎咨询”。不写优惠、不写最低价。
4. 位置和交通：地铁、公交、到周边商圈的时间，只用资料里有的。
5. 周边和配套：楼下有什么、停车、吃饭，资料里有才写。
6. 结尾：请对方留言或私信，说明可以发平面图、约时间看。不留电话和微信号。
- 第一人称，口语，可以有“我们这层”“实际看下来”这样的说法，但不能编造没给的事实和体验。
- 可以在段首用一个简短的小标题（如“关于格局”“交通”），不用表情符号刷屏，全文最多两三个。

## 话题（5–8 个，不带 #）
- 地域搜索词两到三个：广州写字楼、黄埔写字楼、黄埔办公室出租、萝岗、长岭居。
- 品类词两个：写字楼招租、精装办公室、商铺出租、广州酒店推荐、广州潮汕菜。
- 长尾需求词一到两个：创业公司选址、小团队办公室、公司搬家、演唱会住宿攻略、公司团建吃饭。
- 可以加“恒兆广场”和一个交通词（地铁21号线）。

## 按内容类型
- 房源：重点写“这个空间适合多少人、怎么分区、通勤方不方便”。
- 活动与品牌：写成“周末去哪”的分享，时间地点放在第一段。
- 酒店：写成住宿攻略，离演艺中心、科学城多远，房型和早餐、泳池、停车。
- 餐饮：以店里人的口吻介绍（不要假装成来探店的客人），招牌菜、人均可写“欢迎咨询”、适合几个人、有没有包间。
